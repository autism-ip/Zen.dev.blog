# Agent readiness follow-up

The supplied audit scored 97/100 and reported four issues. This change addresses the technical inputs; search placement remains an external observation.

## Findings and changes

- **Brand discovery:** WebSite.name was the generic `Zen`, although the existing title was `Zen (zenhungyep)`. Use the distinctive existing title consistently for WebSite, Open Graph site name, Markdown discovery and API identity. Retain `Zen` and `zenhungyep` as aliases. No business address, press mention or external profile was invented.
- **Raw homepage content:** the previous personal biography was 309 characters and repeated navigation utility classes consumed HTML. Expand the existing five-part biography using the site's published interests; keep the removed “About this site” section absent. Share navigation styles in CSS with the same desktop/mobile styles and shortcut behavior. Add aria-current for the selected section.
- **Developer discovery:** keep the canonical, indexable `/developers` page and sitemap entry; use the full brand in its description and llms.txt link labels. Link the new function definitions from both the portal and llms.txt. Machine resource URLs are stable; JSON documents are not substituted for an indexable HTML guide.
- **Function calling:** the reported 8/19 typed count matches the eight operations with input parameters. The other eleven GET operations legitimately take no input. OpenAPI 3.1 permits this; do not add fictitious query parameters or GET request bodies. Publish `/tools.json` as standard OpenAI Responses API function definitions generated from the same OpenAPI source. All 20 operations (including the new discovery endpoint) have explicit object argument schemas, including empty objects for zero-input operations. Optional fields remain optional with `strict: false`. Query and JSON body arguments are grouped separately and documented. Existing human-only/owner-only restrictions remain explicit.

## Validation

npm run test:coverage -- --coverage.include=src/lib/agent/function-tools.js --coverage.include=src/components/navigation-link.jsx --coverage.include=src/app/tools.json/route.js

For a local deployment, Next middleware captures the trusted proxy setting at build time. Set `TRUSTED_CLIENT_IP_HEADER=x-real-ip` for the build and server, then run:

```sh
AGENT_VERIFY_LOCAL_IP=8.8.4.23 node scripts/verify-agent-readiness.mjs http://127.0.0.1:3100
node scripts/verify-seo.mjs http://127.0.0.1:3100
```

Only configure this trusted header behind a gateway that overwrites it. Vercel uses its own controlled identity. POST probes use invalid input and never publish content. The checks traverse every documented public operation, machine file, and sitemap HTML/Markdown URL, plus errors, quota headers, schema shape, canonical URLs, social images and broken links.

Initial local verification: 163 tests passed; new adapter/route/navigation code has 100% statement/line/function coverage and 89.47% branch coverage. Raw HTML supplies 1,066 visible text characters after removing script/style, with a 5.68% text-to-markup ratio. This ratio is our reproducible measurement, not an assertion about Ora's proprietary extraction. All 55 HTTP readiness checks and the full SEO crawl passed. Browser comparison confirmed identical computed desktop navigation styles and no runtime errors. Redocly CLI 2.6.0 validated the OpenAPI 3.1 document; its 20 advisory `security-defined` warnings concern the existing lack of formal transport security schemes. Reads are unauthenticated; the legacy owner credential is embedded in the JSON body and cannot truthfully be represented as a standard OpenAPI apiKey header/query/cookie scheme. Descriptions and body schema document that restriction. Changing owner authentication is outside this compatibility-preserving change.

## External limitations and follow-up

- Request indexing of `/` and `/developers`, and submit `/sitemap.xml` in the verified Google Search Console property. This requires owner/full-user access; no Search Console change is claimed here.
- Google says recrawling can take days to weeks. Index inclusion, title selection, ranking for the generic word “Zen”, and sitelinks are not guaranteed by metadata changes.
- Consistent branding on owned social profiles and genuine links from relevant projects may help discovery. Changing those profiles or registering listings is a separate owner decision. A personal blog should not fabricate local-business NAP data.
- Is Agentic reports may use cached Ora evidence or a single search sample. Record `scanned_at` with the final CLI result. An old scan or a remaining name-search warning is not evidence that the deployed schemas are missing.
- `/tools.json` is an explicitly documented application resource, not a new universal discovery protocol. Clients still execute the HTTP operations; it grants no access rights. No OpenAI API credentials are required to serve or validate it, and no live paid model request is claimed.
